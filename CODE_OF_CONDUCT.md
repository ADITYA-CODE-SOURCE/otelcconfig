# Code of Conduct

This project follows the
[Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We as members, contributors, and leaders pledge to make participation in our
community a harassment-free experience for everyone, regardless of age, body
size, visible or invisible disability, ethnicity, sex characteristics, gender
identity and expression, level of experience, education, socio-economic status,
nationality, personal appearance, race, caste, color, religion, or sexual
identity and orientation.

## Enforcement

Instances of abusive, harassing, or otherwise unacceptable behavior may be
reported by opening a private security advisory or contacting the repository
owner via GitHub.

This project is independent and not affiliated with the OpenTelemetry project.
For OpenTelemetry community conduct matters, see the
[OpenTelemetry Code of Conduct](https://github.com/open-telemetry/community/blob/main/code-of-conduct.md).
