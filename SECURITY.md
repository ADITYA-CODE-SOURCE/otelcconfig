# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| `main` / latest release | Yes |
| Older tags | Best effort |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead:

1. Use GitHub's private
   [Security Advisories](https://github.com/ADITYA-CODE-SOURCE/otelcconfig/security/advisories/new)
   feature, or
2. Contact the repository owner via GitHub.

Include:

- Description of the issue
- Steps to reproduce
- Affected versions
- Potential impact

We will acknowledge receipt within a reasonable time and coordinate a fix.

## Scope notes

This repository is an independent prototype. It is not part of the official
OpenTelemetry security response process. For vulnerabilities in official
OpenTelemetry components, follow
[OpenTelemetry security policies](https://github.com/open-telemetry/community/blob/main/security.md).
